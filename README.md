# NexaCart

A lightweight, responsive storefront concept for an AI-powered shopping experience. Built with plain HTML, CSS, and JavaScript so it can be hosted directly on GitHub Pages without a build step.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish the site from `index.html`.

## Included

- Responsive storefront with product categories, sorting, and search
- “Smart picks” intent-based product matching
- Persistent shopping bag and wishlist using browser local storage
- Newsletter sign-up interaction and accessible cart drawer

Product checkout and newsletter submission are front-end demo interactions; connect a commerce or email provider before accepting real orders or addresses.
